# @nexusmind/frontend 普通用户版改造方案

> 基于现有 Vue 3 前端，逐步改造为面向普通用户的 AI 伙伴界面

---

## 一、改造原则

### 保留什么

- 现有的 Vue 3 + TypeScript + Vite 架构
- 已实现的 8 个个人助理模块（Todos、Habits、Moods 等）
- 对话控制台的核心逻辑
- 用户画像和心理分析功能

### 改造什么

| 当前状态                           | 普通用户版目标                |
| ---------------------------------- | ----------------------------- |
| 多页面复杂布局                     | 简化为单页面 + 侧边栏         |
| 技术术语（Agent、Skill、Sentinel） | 用户语言（AI 设置、安全守护） |
| 配置分散在多个页面                 | 集中在一个设置中心            |
| 需要理解概念才能使用               | 开关式操作，无需理解          |

### 新增什么

- 引导式初始设置流程
- 行为开关面板
- 数据透明面板（"AI 知道关于我的事"）
- 安全日志可视化
- 桌面应用打包（Electron/Tauri）
